📧 AgentMail 邮箱检查报告

❌ 检查失败

任务

检查 moshang@agentmail.to 未读邮件并标记已读。

结果

AgentMail API 返回 403 Forbidden（CloudFront 拦截），无法获取邮件列表。

尝试的方法

  • 直接 HTTP GET api.agentmail.to/v0/inboxes/moshang@agentmail.to/messages
  • Node.js SDK (agentmail npm 包) 调用 client.inboxes.messages.list()
  • 带 Accept: application/json 与标准 User-Agent 的请求

所有方式均被 CloudFront 返回 403 Request blocked。

可能原因

  • API Token 已过期或被吊销
  • 当前出口 IP 被 CloudFront WAF 规则拦截
  • AgentMail 服务当前存在可用性问题
  • 账号或 Pod 已被停用

建议

  1. 在 AgentMail Dashboard 检查 Token 状态与额度
  2. 尝试从其他网络环境访问确认是否为 IP 封锁
  3. 如长期不可用，考虑更换邮件通知渠道（如 Bark / 企业邮箱）
